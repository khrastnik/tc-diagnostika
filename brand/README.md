# Znamka Toplolog

Znak: **hiša z utripom** – »-log« kot zdravnik za toplotne črpalke; utrip gre iz hladnega (modra) v toplo (oranžna). Sporočilo: redni pregled = skrb za zdravje naprave.

| Datoteka | Uporaba |
| --- | --- |
| `toplolog-znak.svg` | glavni znak (zaobljen kvadrat), ikona zavihka (`public/favicon.svg`), Reels |
| `toplolog-znak-brez-ozadja.svg` | znak brez ploščice, za temne podlage |
| `toplolog-znak-kvadrat.svg` | polna površina, za profilne slike in ikone aplikacij |
| `toplolog-profilna-1080.png` | profilna slika Instagram / Facebook / TikTok |
| `toplolog-ikona-512.png` | ikona 512 px (Google, aplikacije) |
| `toplolog-logotip-svetlo.png` / `-temno.png` / `-prosojno.png` | vodoravni logotip z napisom in sloganom |

Barve: temna `#0e1f1a`, zelena `#0a7d65` / `#13a07f` / svetla `#6ed8b8`, modra `#5aa9e6`, oranžna `#ff8a65`. Pisava: Plus Jakarta Sans (800 za napis).
Napis: »Topl« v osnovni barvi + »olog« v zeleni. Slogan: »toplotne črpalke, razložene po domače«.
